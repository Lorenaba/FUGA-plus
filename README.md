Visión del proyecto

FUGA+ es una aplicación móvil diseñada para ayudar a jóvenes y estudiantes a comprender mejor sus hábitos de gasto.

Permite registrar gastos de manera sencilla mediante texto y utiliza Inteligencia Artificial para interpretar y clasificar automáticamente la información.

A partir de los gastos registrados, el sistema analiza patrones y detecta posibles fugas de dinero relacionadas con gastos pequeños y repetitivos.

El MVP se enfocará en el registro, clasificación, almacenamiento y análisis básico de gastos, dejando funcionalidades como voz, conexión bancaria y pagos fuera del alcance inicial.

El proyecto será desarrollado durante 12 semanas como parte de un proyecto académico de Ingeniería de Sistemas.
